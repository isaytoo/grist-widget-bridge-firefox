Signaler un problème ou poser une question

Ouvrez un ticket sur le dépôt GitHub de l'extension. Décrivez ce que vous faisiez, ce que vous attendiez, et joignez si possible les lignes de la console qui commencent par [GristBridge].

Vérifier que l'extension fonctionne

Ouvrez les outils de développement (F12), onglet Console, sur la page Grist qui contient le widget.

MessageSignification
[GristBridge] Bridge installéLe relais est présent dans la page Grist.
[GristBridge] Handshake avec https://…Le widget a trouvé le relais : l'envoi de fichiers passera par lui.
[GristBridge] Origine refusée : https://…L'adresse du widget n'est pas déclarée. Sur la page du widget, cliquez sur « + Comme widget ».

Problèmes fréquents

Le message « Bridge installé » apparaît deux fois

Deux versions de l'extension sont actives en même temps. Elles répondraient toutes deux au widget, et la plus ancienne peut faire échouer l'envoi. Dans chrome://extensions, n'en gardez qu'une.

Rien ne change après une mise à jour du widget

Le navigateur sert encore l'ancienne version, gardée en cache. Modifiez le paramètre _cb= dans l'adresse du widget (panneau de droite de Grist, « URL personnalisée »), ou cochez « Désactiver le cache » dans l'onglet Réseau des outils de développement, puis rechargez.

L'envoi de fichier échoue sans aucune ligne « Handshake »

Le widget n'a pas interrogé l'extension : soit il ne sait pas le faire (version trop ancienne), soit l'instance Grist n'est pas déclarée et le relais n'a pas été injecté. Vérifiez la présence de « Bridge installé » au chargement de la page.

Grist répond « droits insuffisants »

L'extension ne contourne pas les droits de Grist. Votre compte doit pouvoir écrire dans le document qui reçoit le fichier.

Pour les développeurs de widgets

Le protocole du relais (découverte, puis envoi d'un fichier par message) est décrit dans le README du dépôt.
